## Global CSS Classes Available

### Layout
- `.flex` - Flexbox row
- `.flex-center` - Centered flex
- `.flex-between` - Space-between
- `.flex-column` - Column direction
- `.container` - Max-width 1200px

### Spacing
- `.gap-sm`, `.gap-md`, `.gap-lg` - Flex gaps
- `.mt-sm`, `.mt-md`, `.mt-lg` - Margin top
- `.mb-sm`, `.mb-md`, `.mb-lg` - Margin bottom

### Colors
- `.text-primary`, `.text-error`, `.text-muted`
- `.bg-primary`, `.bg-light`, `.bg-error`

### Buttons
- `.btn` - Primary button
- `.btn.ghost` - Outlined button

### Responsive
- `@media (max-width: 768px)` - Tablet & mobile
- `@media (max-width: 480px)` - Mobile only

## How to Test

### Desktop
1. Open http://localhost:3000
2. See full navigation with Home 🏠 and Plants 🌿 buttons
3. Search bar visible
4. All buttons visible

### Tablet (768px - 480px)
1. Press F12 in Chrome
2. Click device toolbar (Ctrl+Shift+M)
3. Set width to 600px
4. See compact navigation with menu button
5. Labels hidden, icons visible

### Mobile (<480px)
1. Device toolbar width: 375px
2. See hamburger menu (☰)
3. Search bar full width
4. Navigation icons only
5. Tap menu to see full navigation
